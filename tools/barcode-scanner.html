Barcode und QR-Code online scannen – ohne App

Dieser Scanner erkennt gängige Barcode- und QR-Code-Formate direkt über die Kamera deines Geräts oder aus einem hochgeladenen Foto, ganz ohne separate App installieren zu müssen. Das ist praktisch, wenn du schnell einen Code auf einer Verpackung, einem Dokument oder einem Bildschirm auslesen möchtest, während du gerade an deinem Computer oder Smartphone-Browser arbeitest.

Unterstützte Formate

Der Scanner erkennt sowohl zweidimensionale QR-Codes als auch klassische eindimensionale Barcodes wie Code128, EAN-13, EAN-8, UPC und Code39 – also praktisch alle Formate, die im Alltag auf Produktverpackungen, Tickets, Visitenkarten oder Versandetiketten vorkommen.

Scannen per Webcam

Im Webcam-Modus greift das Tool nach deiner Erlaubnis auf die Kamera deines Geräts zu und sucht laufend nach einem erkennbaren Code im Bild. Sobald ein Code erkannt wird, zeigt das Tool automatisch den decodierten Inhalt sowie das erkannte Format an. Halte den Code dazu möglichst ruhig, gut beleuchtet und formatfüllend vor die Kamera.

Scannen aus einem hochgeladenen Foto

Wenn eine Live-Kamera nicht verfügbar oder nicht praktikabel ist (zum Beispiel am Desktop-PC ohne Webcam, oder wenn du bereits ein Foto des Codes hast), kannst du stattdessen ein Bild hochladen. Das Tool analysiert das Bild direkt nach dem Hochladen und zeigt das Ergebnis auf dieselbe Weise an.

Erkannter Inhalt: Text, Link oder mehr

Ein QR-Code kann sehr unterschiedliche Inhalte codieren – reinen Text, eine Webadresse, WLAN-Zugangsdaten, eine Visitenkarte (vCard) oder eine Zahlungsinformation. Erkennt das Tool, dass der decodierte Inhalt wie eine Webadresse aussieht, erscheint zusätzlich ein direkter "Link öffnen"-Button.

Verlauf der letzten Scans

Jeder erfolgreiche Scan wird in einem Verlauf unterhalb des Scanners gespeichert, sodass du mehrere Codes hintereinander scannen kannst, ohne das Ergebnis jedes Mal separat kopieren zu müssen, bevor du zum nächsten Code wechselst. Der Verlauf wird nur lokal in deinem Browser gespeichert.

Datenschutz

Die gesamte Bilderkennung läuft lokal in deinem Browser. Weder das Kamerabild noch ein hochgeladenes Foto werden an einen Server übertragen oder gespeichert.
