CSV in JSON umwandeln: Der Konverter für deutsche Dateien

CSV ist das Austauschformat für Tabellen: Excel exportiert es, Shopsysteme, Buchhaltungsprogramme und Datenbanken liefern es, und fast jede Software kann es lesen. JSON dagegen ist das Standardformat moderner Webanwendungen, APIs und JavaScript-Programme. Wer Daten aus einer Tabelle in eine Webanwendung bringen will, muss deshalb häufig CSV in JSON umwandeln. Genau das erledigt der CSV-zu-JSON-Konverter von Toolyfix – direkt im Browser, ohne Upload, ohne Anmeldung und mit besonderem Blick auf typisch deutsche Eigenheiten: Semikolon als Trennzeichen, Komma als Dezimalzeichen und Dateien mit älterer Windows-Kodierung.

Zusätzlich funktioniert das Tool in die Gegenrichtung. Mit „JSON → CSV“ machst du aus einem JSON-Array wieder eine Tabelle, die du in Excel oder Google Tabellen öffnen kannst. Beide Richtungen laufen lokal, deine Daten verlassen deinen Rechner nicht.

Funktionen des Konverters

  • Automatische Erkennung des Trennzeichens: Semikolon, Komma, Tabulator oder Pipe werden anhand der ersten Zeile erkannt. Du kannst das Trennzeichen aber auch fest vorgeben.
  • Korrektes Lesen nach RFC 4180: Felder in Anführungszeichen, doppelte Anführungszeichen innerhalb von Feldern und sogar Zeilenumbrüche innerhalb von Feldern werden richtig verarbeitet.
  • Zahlen erkennen: Aus „42“ wird die Zahl 42, aus „true“ der Wahrheitswert true. Postleitzahlen und andere Werte mit führenden Nullen bleiben dabei Text, damit aus „01067“ nicht 1067 wird.
  • Deutsches Zahlenformat: Ist das Dezimalkomma aktiv, wird „1.234,56“ zu 1234.56. Standardmäßig geschieht das automatisch bei Semikolon- und Tabulator-Dateien.
  • Vier JSON-Formate: Array von Objekten, Array von Arrays, ein Objekt mit der ersten Spalte als Schlüssel und JSON Lines für große Datenmengen.
  • Einrückung nach Wunsch: Zwei oder vier Leerzeichen, Tabulator oder minimiert für kleine Dateien.
  • Dateikodierung wählen: Alte Excel-Exporte liegen oft in Windows-1252 vor. Mit der passenden Kodierung erscheinen Umlaute korrekt.
  • Tabellenvorschau: Die ersten 50 Zeilen siehst du als Tabelle, bevor du das Ergebnis kopierst oder herunterlädst.
  • Hinweise auf Probleme: Zeilen mit abweichender Spaltenzahl und doppelte Schlüssel werden gemeldet.

So wandelst du CSV in JSON um

  1. Füge den CSV-Text in das Eingabefeld ein oder lade eine Datei hoch.
  2. Prüfe, ob das Trennzeichen richtig erkannt wurde. Die Statistik unter der Überschrift zeigt es an.
  3. Entscheide, ob die erste Zeile Spaltennamen enthält. Ohne Kopfzeile erzeugt das Tool die Namen „spalte_1“, „spalte_2“ und so weiter.
  4. Wähle das JSON-Format und die Einrückung.
  5. Kopiere das Ergebnis oder lade es als .json-Datei herunter.

Welches JSON-Format passt zu meinem Zweck?

Array von Objekten

Das ist die häufigste Form. Jede Zeile wird zu einem Objekt, dessen Schlüssel die Spaltennamen sind. Sie eignet sich für APIs, Frontend-Anwendungen und Datenbank-Importe, weil jeder Wert einen sprechenden Namen hat.

Array von Arrays

Hier bleibt die Tabellenstruktur erhalten: Die erste Zeile enthält die Spaltennamen, die weiteren die Werte. Das Format ist kompakt und passt zu Diagrammbibliotheken, die Daten als Matrix erwarten.

Objekt nach erster Spalte

Die erste Spalte wird zum Schlüssel, alle anderen Spalten bilden das zugehörige Objekt. Das ist praktisch für Nachschlagetabellen, etwa Artikelnummern mit Preis und Bezeichnung. Beachte, dass doppelte Schlüssel einander überschreiben. Das Tool weist darauf hin.

JSON Lines

Bei sehr großen Dateien wird jeder Datensatz in eine eigene Zeile geschrieben. Das lässt sich Zeile für Zeile verarbeiten, ohne die gesamte Datei im Speicher zu halten. Viele Datenwerkzeuge, Log-Systeme und Machine-Learning-Pipelines nutzen dieses Format.

Typische deutsche Stolpersteine bei CSV-Dateien

Semikolon statt Komma

Weil im deutschen Zahlenformat das Komma das Dezimalzeichen ist, trennt deutsches Excel CSV-Felder mit einem Semikolon. Programme aus dem englischsprachigen Raum erwarten dagegen ein Komma. Wenn die Daten in einer einzigen Spalte landen, stimmt das Trennzeichen nicht. Die automatische Erkennung dieses Tools löst das in den meisten Fällen.

Umlaute werden falsch angezeigt

Erscheinen statt „ä“ oder „ü“ seltsame Zeichen, liegt eine Kodierungsabweichung vor. Ältere Excel-Dateien nutzen Windows-1252, moderne Systeme UTF-8. Wähle im Tool die passende Kodierung für deine Datei. Beim Export aus JSON nach CSV fügt die Option „UTF-8-Markierung“ ein Byte-Order-Mark ein, damit Excel die Datei sofort richtig öffnet.

Dezimalkomma und Tausenderpunkt

Die Zahl „1.234,56“ ist für Excel in Deutschland völlig normal, für JSON aber ungültig. JSON kennt nur den Punkt als Dezimalzeichen. Der Konverter wandelt deshalb um, wenn das Dezimalkomma aktiv ist. Bei internationalen Dateien wählst du „Punkt“.

Führende Nullen gehen verloren

Postleitzahlen wie „01067“, Artikelnummern oder Telefonnummern dürfen nicht als Zahl interpretiert werden. Das Tool lässt solche Werte als Text. Möchtest du wirklich alles unverändert als Text haben, deaktiviere „Zahlen und true/false erkennen“.

Zeilen haben unterschiedlich viele Spalten

Häufig liegt es an einem Trennzeichen innerhalb eines Feldes, das nicht in Anführungszeichen steht. Prüfe die Warnung des Tools und die Tabellenvorschau: Die Zeile, in der die Werte verrutschen, zeigt die Fehlerstelle.

JSON in CSV umwandeln

Umgekehrt ist die Konvertierung ebenso einfach: Füge ein JSON-Array ein, und das Tool erzeugt eine Tabelle. Verschachtelte Objekte werden mit Punkt-Schreibweise flach gemacht, aus {"adresse":{"ort":"Köln"}} wird also die Spalte „adresse.ort“. Listen innerhalb eines Feldes werden als JSON-Text eingetragen. Die Spalten ergeben sich aus allen vorkommenden Schlüsseln, auch wenn nicht jedes Objekt alle besitzt. Fehlende Werte bleiben leer. Für deutsche Excel-Versionen stellst du Semikolon und Dezimalkomma ein, sodass sich die Datei per Doppelklick öffnen lässt und Zahlen korrekt als Zahlen erkannt werden.

Praxisbeispiele für die Konvertierung

  • Webshop: Produktdaten aus Excel werden als JSON für ein Shop-Frontend oder einen Import bereitgestellt.
  • Webentwicklung: Eine Tabelle mit Übersetzungen oder Öffnungszeiten wird als JSON-Datei in eine statische Webseite eingebunden, ganz ohne Datenbank.
  • Datenanalyse: Messwerte werden für ein Diagramm aufbereitet. Anschließend lässt sich daraus mit dem Balkendiagramm-Tool eine Grafik erstellen.
  • Datenmigration: Kundenlisten wandern von einem System ins nächste, das JSON-Importe verlangt.
  • Tests und Prototypen: Beispieldaten für eine Anwendung werden in einer Tabelle gepflegt und per Knopfdruck in JSON gewandelt.

Tipps für saubere Ergebnisse

  • Verwende eindeutige, einfache Spaltennamen ohne Sonderzeichen. Sie werden zu den JSON-Schlüsseln.
  • Lösche leere Spalten und Zeilen in der Tabelle, bevor du exportierst.
  • Prüfe das Ergebnis mit dem JSON-Formatter. Er zeigt Syntaxfehler und strukturiert die Ausgabe.
  • Achte bei sensiblen Daten darauf, dass die Datei nur dort gespeichert wird, wo sie hingehört.
  • Sichere die Originaldatei, bevor du Daten weiterverarbeitest.

Datenschutz und Grenzen

Die Umwandlung geschieht komplett im Browser. Das macht das Tool auch für interne Listen geeignet, die du nicht auf einen fremden Server laden möchtest. Sehr große Dateien mit mehreren hunderttausend Zeilen können je nach Gerät langsam werden, weil dein Browser alles im Arbeitsspeicher hält. In solchen Fällen empfiehlt sich das Format JSON Lines oder eine Aufteilung der Datei. Die Tabellenvorschau zeigt aus Leistungsgründen nur die ersten 50 Zeilen, das Ergebnis enthält aber alle Datensätze.

Häufige Fragen zum CSV-zu-JSON-Konverter

Ist der Konverter kostenlos?

Ja, ohne Anmeldung und ohne Begrenzung der Nutzung.

Wird meine Datei hochgeladen?

Nein. Die Datei wird nur in deinem Browser gelesen.

Kann ich Excel-Dateien (.xlsx) direkt verwenden?

Nein, das Tool liest CSV und Text. Speichere deine Excel-Tabelle zuvor über „Speichern unter“ als CSV, am besten als „CSV UTF-8“.

Warum steht in meinem JSON alles in Anführungszeichen?

Dann ist „Zahlen und true/false erkennen“ deaktiviert, oder die Werte enthalten Zeichen, die nicht als Zahl lesbar sind, etwa Währungssymbole oder Leerzeichen innerhalb der Zahl.

Wie gehe ich mit Datumsangaben um?

Datumswerte bleiben Text, weil JSON kein eigenes Datumsformat besitzt. Verwende nach Möglichkeit das internationale Format JJJJ-MM-TT, das sich in vielen Programmen eindeutig lesen lässt.
