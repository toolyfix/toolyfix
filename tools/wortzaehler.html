Wie wird gezählt?

Wörter werden anhand von Leerzeichen und Zeilenumbrüchen getrennt. Sätze werden anhand von Punkt, Ausrufe- und Fragezeichen erkannt. Die Lesezeit wird mit durchschnittlich 200 Wörtern pro Minute berechnet – ein gängiger Richtwert für deutschsprachige Texte.

Der gesamte Text bleibt in deinem Browser. Es wird nichts an einen Server gesendet oder gespeichert.
