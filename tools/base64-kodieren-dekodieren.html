Was ist Base64 und wofür wird es gebraucht?

Base64 ist ein Verfahren, um beliebige binäre Daten (zum Beispiel ein Bild oder eine PDF-Datei) in eine Zeichenkette aus reinen Text-Zeichen umzuwandeln, die sicher in Systemen übertragen oder gespeichert werden kann, die eigentlich nur reinen Text verarbeiten können – etwa in E-Mails, JSON-Dateien, URLs oder CSS-Dateien. Der Name kommt daher, dass nur 64 verschiedene Zeichen verwendet werden (Buchstaben A–Z und a–z, Ziffern 0–9, sowie zwei Sonderzeichen).

Text in Base64 umwandeln

Im Textmodus wird jedes Zeichen deines eingegebenen Textes zunächst in seine Byte-Darstellung übersetzt und anschließend nach dem Base64-Verfahren kodiert. Das Ergebnis sieht auf den ersten Blick wie eine zufällige Zeichenkette aus, enthält aber exakt die Information, um den ursprünglichen Text wieder herzustellen – und genau das passiert beim Klick auf "Base64 → Text".

Dateien in Base64 umwandeln – wofür ist das nützlich?

Eine ganze Datei (zum Beispiel ein kleines Bild oder eine Schriftart) lässt sich ebenfalls in Base64 umwandeln und dann direkt in HTML, CSS oder JSON einbetten, ohne eine separate Datei referenzieren zu müssen – praktisch bei kleinen Icons, Favicons oder Inline-Bildern in E-Mail-Vorlagen, wo externe Bildverknüpfungen manchmal blockiert werden. Der Nachteil: Die Base64-Darstellung ist etwa ein Drittel größer als die Originaldatei, weshalb sich das Verfahren vor allem für kleine Dateien lohnt.

Base64 zurück in eine herunterladbare Datei umwandeln

Hast du bereits einen Base64-String (zum Beispiel aus einer API-Antwort, einer Konfigurationsdatei oder einem Code-Snippet) und möchtest daraus wieder eine echte Datei machen, kannst du den String im unteren Bereich einfügen, einen Dateinamen mit passender Dateiendung vergeben, und die Datei direkt herunterladen. Das Tool erkennt dabei automatisch, ob der String noch ein "data:...;base64," Präfix enthält, und entfernt dieses bei Bedarf automatisch.

Standard-Base64 vs. URL-sichere Variante

Die Standard-Base64-Kodierung verwendet die Zeichen + und /, die in einer URL eine spezielle Bedeutung haben und dort zu Problemen führen können. Die URL-sichere Variante ersetzt diese beiden Zeichen durch - und _, sodass der kodierte String direkt und unverändert als Teil einer URL (zum Beispiel als Parameter) verwendet werden kann, etwa bei JSON Web Tokens (JWT), die genau dieses URL-sichere Format nutzen.
